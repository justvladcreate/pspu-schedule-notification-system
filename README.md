# Что это?
Это система персонализированных уведовлений для студентов вуза ПГГПУ через телеграм бота.

## Как это работает?
Система скачивает онлайн таблицу, "расшифровывает" данные с помощью алгоритмов парсинга и помощи LLM gemma 4, которая основана на облачном сервере [Ollama](https://ollama.com/library/gemma4).
После эти данные сраниваюстя с предыдущей версией расписания и рассылаются индивидуально подписавшимся людям.

### System workflow

Parser:

Цикл повторяется раз в 15 минут.

1. Копируем расписание из открытого источника Google Sheets
2. Достаём информацию из таблицы расписания с учётом особенностей блока данных
3. Проверяем наличие различий в предыдущем варианте информации
   1. Если нет предыдущего варианта, пропускаем
4. Отправляем сообщение в ТГ всем пользователям, подписанным на рассылку

TGBot:

Работает всегда, имеет защиту от DDoS атак

1. Принимает команды /start и /stop
   1. /start - открывает стартовое меню, в котором пользователь может выбрать вариант подписки
   2. /stop - отписывает пользователя и удаляет из БД
2. Может отправлять сообщения в ТГ каналы
